How Reports are Computed (Viva Explanation)

In this system, analytics are calculated dynamically using SQL aggregate functions such as SELECT COUNT(*) FROM ... GROUP BY status and GROUP BY type. These queries execute directly on the local SQLite3 database and are structured into clean Python dictionaries inside models.py. The results are rendered into responsive charts on the frontend using Chart.js, with an automatic pure-CSS fallback if running offline.
